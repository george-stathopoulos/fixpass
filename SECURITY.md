# Security policy

Fixpass handles access to WordPress sites, so security reports are taken seriously.

## Reporting a vulnerability

Please **don't** open a public issue. Use GitHub's private reporting instead: **Security → Report a vulnerability** on [this repository](https://github.com/george-stathopoulos/fixpass/security/advisories/new).

Include what you found, how to reproduce it, and the Fixpass version. You'll get a reply within a few days.

## Supported versions

The latest release.

How Fixpass protects access is described in [docs/security.md](docs/security.md).
