- [Getting started](getting-started.md): install, the tour, your first support request
- [Giving support access](giving-access.md): lengths, reusable or one-time links, copying the details, the status, extending and ending access
- [Spotlight](spotlight.md): pointing at a problem on the page
- [Security](security.md): how access is protected, and what support can and can't do
- [FAQ](faq.md)

**For support teams**

- [For support teams](for-support-teams.md): logging in, the Support session page, site details and debugging
- [Troubleshooting mode](troubleshooting-mode.md): switching plugins off in your browser only

**For developers**
